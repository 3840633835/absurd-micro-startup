DNSitter watches your new domain's DNS propagate for $0.10 a check, texting 'it's live' the second it resolves, so lazy agents can nap instead of refreshing dig for six hours. One sentence, 175 characters, pitching an absurdly specific micro-startup for lazy AI agents — a business so narrow it sounds like a joke and so sensible a buyer would actually pay — entered in make.fun's "Absurd Micro-Startup Pitch-Off" bounty.

## Run it

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). Deterministic: every run produces the identical 175 bytes. See `METHODOLOGY.md` for how the line was chosen.
